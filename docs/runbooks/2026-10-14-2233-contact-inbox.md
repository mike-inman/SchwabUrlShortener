# Reading contact messages — 2026-10-14 22:33 CDT

Contact submissions remain in PostgreSQL whether email delivery succeeds or fails. The signed-in inbox is at `https://ziplio.io/admin/messages`. After Michael's admin identity is configured and deployed, sign in with that customer account and select **Messages** in the header. The badge is the number of unhandled messages. The page shows newest first; **Load older messages** uses a stable cursor. Each entry shows submitter name and email, subject, message, local received time, notification status, and a **Mark handled** action. New submissions and handled changes update through Redis hints on the existing Blazor WebSocket path. If live updates disconnect, the page warns and resynchronizes on reconnection.

The API is the authorization boundary: `GET /api/admin/contact-messages` and `POST /api/admin/contact-messages/{id}/handled` require a delegated `access_as_user` token and the `ContactInboxAdmin` policy. The Web link and page are hidden from non-admins, but this is only a UI convenience. With no configured admin entries, nobody has inbox access. The API response omits the stored client key hash.

## Who is an admin

`Admin:Subjects` contains exact `issuer|subject` pairs matching the validated API access token's single `iss` and `sub` claims. This is the same stable identity key used by `external_identities`; display names and email addresses do not grant access. The production Bicep template's secure `contactAdminSubject` parameter sets `Admin__Subjects__0` on `ca-shortener-api` when nonempty. It is empty by default. Confirm the exact pair against Michael's `external_identities` row or the customer tenant before deploying. Do not infer it from an email address, and do not put it in Git or this runbook.

To add another admin, extend the Bicep parameter contract with a second reviewed `Admin__Subjects__1` entry, using that person's exact issuer and subject. Run a fresh what-if and obtain Michael's approval before applying it. Keep the existing entry until the added account has passed a signed-in access check. Never grant a general tenant-wide admin match.
